# 🥈 Skill Mill: Code of Duty @ Unscript Rookies 2k22

**1st runner-up** at *Unscript Rookies 2k22*, a 24-hour national-level hackathon.

Skill Mill is an online learning platform where people can **connect, learn and share knowledge**. Verified educators publish courses, and students learn from them and get their doubts solved one-on-one.

![React](https://img.shields.io/badge/React-61DAFB?logo=react&logoColor=black) ![MUI](https://img.shields.io/badge/Material%20UI-007FFF?logo=mui&logoColor=white) ![WebSocket](https://img.shields.io/badge/WebSocket-realtime-black)

## ✨ Features
- 😊 Easy to use for learners of **all ages**
- 📜 Browse and enroll in courses across many domains
- ✔️ **Admin verification** of educators before they can publish
- 📂 Upload several video lectures and notes for each course
- 📞 **1:1 doubt solving** through real-time chat (WebSockets) or video call
- 📑 Course feedback, plus **push notifications** for new courses
- 👩‍🏫 Separate dashboards for **Student**, **Teacher** and **Admin**

## 🚀 Run locally
```bash
npm install
npm start      # http://localhost:3000
```

## 🛠️ Tech
React, React Router, Material UI, Styled Components, Framer Motion, AOS, WebSockets, EmailJS, Formik, Axios
